# RDP4 适配调查

核验日期：2026-10-18。当前只完成版本检测与初步界面观察，不支持分析执行。

## 已取得的证据

- 使用者电脑上存在 RDP4，Windows 文件属性 ProductName 为 rdp4，ProductVersion 与 FileVersion 均为 4.101。
- 通过项目 `inspectSoftware` 读取该文件，返回 metadata_match 和版本 4.101。没有为取得版本而启动程序。
- 随后通过 Computer Use 启动已安装软件，主窗口标题为 Recombination Detection Program v.4.101。
- 主窗口截图可见 Open、Options、Run 等按钮；无已载入分析数据。
- Windows 可访问性树只返回主窗口和标题栏，没有提供按钮索引，不能直接采用常规控件定位方式。
- 对 Open 和 Options 的初步点击后，返回截图未显示变化，窗口列表未出现新的文件对话框。不能据此断言按钮无效、软件卡死或完整流程不可自动化。

## 实施约束

不把截图坐标写成正式适配器。不以进程启动作为分析成功。未核验加载、参数设置、启动、完成和结果导出前，operations 保持为空。
