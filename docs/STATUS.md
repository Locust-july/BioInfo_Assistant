## 建议下一位开发者首先做

1. 按 README 克隆、安装依赖、测试和构建。
2. 本地安装插件，在真实 Work 聊天调用，记录客户端版本、结果和复现步骤。
3. 如 UI 无法出现，首先排查工具资源映射、UI 桥接和 Node.js 启动路径。
4. 验收界面后，与所有者确定首款软件及真实任务，再实现软件资料和适配器。

## 交接记录规则

每个 PR 更新本文件，写明完成事项、测试命令与结果、未解决问题及下一步。多人各自使用分支，避免同时修改同一文件。不要把“本地测试通过”写成“客户端或远端 CI 验收通过”。
