# 生信小助手首版开发规格

## 已知条件与证据

- 产品名称：生信小助手；目标版本：V1.0，内部开发版本从 0.1.0 开始。
- 用户提供的客户端：ChatGPT 26.1013.4894.0，Work 模式可调用插件。
- 用户此前已开展可行性验证，但本项目没有收到 MCP 配置、验证代码及调用日志。
- 当前仓库在初始化前为空；客户端具备插件能力不等于本项目插件已经接入。
- 首个外部生信软件、任务、参数、输入和参考结果均待定。

## 原始实施顺序与验收

以下为初始规划，最新完成状态以 STATUS.md 为准。

1. 基础诊断：本地命令返回项目状态及可配置数据目录。当前已实现。
2. MCP 接入：实现只读健康检查工具，在指定客户端完成发现与真实调用，保存脱敏配置和验证记录。尚未实现。
3. 最小页面：显示插件状态和空软件列表；验证页面展示、重开及刷新。尚未实现。
4. 软件目录：加入第一款外部软件，记录版本探测方法、来源、引用及支持操作。
5. 真实任务：确定输入和参考输出后实现适配器及任务执行。
6. 干净机器安装与试用：验证运行依赖、安装方式、目录权限及卸载行为。

## 拟定接口  尚未实现

| 接口 | 用途 | 前置条件 |
| --- | --- | --- |
| health | 返回开发版本、平台和能力状态 | MCP 接入 |
| list_software | 软件资料和可用操作 | 软件目录 |
| inspect_software | 探测已登记软件的路径和实际版本 | 对应探测器 |
| validate_task | 校验输入、参数、依赖和输出冲突 | 明确任务规范 |
| submit_task | 接收唯一请求标识，返回任务 ID | 适配器及执行器 |
| get_task | 查询状态、日志摘要和输出 | 持久化任务记录 |
| cancel_task | 请求取消，返回真实状态 | 对应适配器支持 |

不开放任意 shell 命令工具。未知软件和未适配操作返回明确的不支持错误。
状态计划包括 queued、running、cancel_requested、cancelled、succeeded、failed、interrupted。
最终成功需通过对应适配器的输出校验；取消请求不直接记为已停止。

## 目录策略

开发源代码保留在当前工作区。插件安装位置由经验证的客户端安装方式确定。
运行配置、日志与数据库默认存入用户本地应用数据目录，可指定绝对路径。
分析输出按任务独立目录保存，其根目录在实现真实任务时配置。
当前骨架只计算目录，不创建目录、不安装软件、不执行分析。
